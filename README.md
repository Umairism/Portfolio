## 🚀 Quick Start

```bash
# Clone the repo
git clone https://github.com/Umairism/Portfolio.git
cd Portfolio

# Install dependencies
npm install

# Start dev server (http://localhost:3000)
npm start

# Build for production
npm run build
```

**Requirements:** Node.js 16+
